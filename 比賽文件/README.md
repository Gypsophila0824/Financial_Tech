最新正式公告與官方系統結算具有優先性。新版未重新定義費稅精度；指南刪除舊費率段落不等於廢除競賽辦法的費率。Active Share 仍依本地保存的 10/16 後續公告比較雙方前 15 大、最低 15%，不因 schema 版號變動而改回舊規則。
