# 回測股利權益、連續估值與封存

更新日期：2026-10-15。範圍僅限研究用正式策略回測，不修改正式帳本、策略參數或 D-Plan。

## 競賽股利口徑

依 2026-10-05 更新版競賽辦法第六(十二)、註 1 與 Slack 官方問答第 4 頁：除息金額及除權股數均不在除權息當日納入投資組合，由主辦方累積並於初賽結束納入最終 NAV；本系統將現金股利與配股權益延至期末估值，不作為期間內可交易現金或持股。股票分割屬另一類公司行動，規則依辦法六(十二)，尚未實作完整調整流程，遇到事件依下文保護措施停止。

- 除權息日按前一交易日持股計算權益。當日新買進無權益、當日賣出仍保留已取得權益。
- 權益獨立存在 `DividendLedger`，不影響 `PortfolioState.cash`、可交易股數及後續下單。
- 不足一張但至少整數股的配股保留；不足一股的捨入方式不猜測，停止並要求確認。
- 未指定 `--terminal-date` 時，即使回測已結束也不釋放權益，避免短區間把股利提前再投資。
- 指定期末日必須等於本次最後交易日；以該日真實收盤價估值，包括已賣出股票的配股權益。缺價不使用舊價。
- 期末 `nav = trading_nav + terminal_dividend_adjustment`。現金、持倉與合規比例仍以交易結算帳本 `trading_nav` 為準；期末調整只反映最終資產價值，不視為買賣或費稅。
- 不對累積配股自動計算下一次股利；若同股票又遇事件，需確認官方權益基數，暫停回測。
- 股票分割、減資、合併等不是股票股利。本版遇已登錄且有曝險的非股利事件即停止；未聲稱已完成其換股、零股、價格及委託基準處理。

## 事件明細

預期位置為 `data/corporate_actions/`，由 `--corporate-actions <明細.json>` 明確指定。系統不內建假股利資料，也不把參考價差當成股利。

明細格式如下，**數值為格式示例，不是真實公告，不可直接用於策略驗證**：

```json
[
  {
    "event_id": "公司代號-除權息日-公告識別",
    "ticker": "2330",
    "ex_date": "2026-10-28",
    "published_at": "2026-10-20T10:00:00+08:00",
    "source": "請填已核實的公告網址或原始文件位置",
    "kind": "dividend",
    "cash_per_share": "2.5",
    "stock_per_share": "0.025",
    "currency": "TWD"
  }
]
```

`cash_per_share` 是每一原持股的台幣股利；`stock_per_share` 是每一原持股的新配股數，**不是股票股利面額元數**。同股票同日的現金及股票股利須合為一筆，重複事件拒絕。公告需有時區，晚於生效日 08:55 的版本不可冒充盤前已知資料。生效日需採實際交易日，遇延期應先核實再匯入。

若知道有分割等事件，可以同格式登錄 `kind: "split"`，股利欄位填 `"0"`，使程式遇曝險時明確停止，而非沿用錯誤股數。這不是分割執行支援。

### 現有資料限制

`data/market/twse_exright.csv` 只有上市除權息前收盤價及參考價，沒有完整現金／配股比率；上櫃 `ref_next` 亦不足以直接推算事件類型。本版利用兩者作缺漏警示：前日持股或待配股權益遇已知事件、卻未提供明細時停止。它們不能證明全市場事件完整。

沒有明細不等於沒有股利。摘要固定標示 `user_supplied_events_not_certified_complete`；需要另補官方核實的事件清單，才可進行含真實股利的驗收。未自動抓取新公告，未納入 CPI、新聞訊號或事件績效分析。

## 執行與輸出

```powershell
# 純回放，權益累積但不提前釋放；未提供事件時仍會檢查已知缺漏
.\.venv\Scripts\python.exe -X utf8 -m src.agent.backtest.runner --start 2026-10-02 --end 2026-10-13

# 明細備妥後，明確指定期末；歷史研究期末是使用者假設，不代表正式賽程
.\.venv\Scripts\python.exe -X utf8 -m src.agent.backtest.runner --start 2026-10-27 --end 2026-11-27 --corporate-actions data/corporate_actions/verified.json --terminal-date 2026-11-27

# 已存在的回測目錄只讀，重播須輸出至另一個新目錄
.\.venv\Scripts\python.exe -X utf8 -m src.agent.backtest.runner --replay output/backtest/<原始run>
```

新增輸出：

| 檔案 | 功能 |
| --- | --- |
| `dividend_entitlements.csv` | 事件 ID、來源、權益股數、現金及配股累計明細 |
| `dividend_ledger.json` | 待入帳權益與期末入帳金額、期末估值價格 |
| `replay_inputs.json` | 每日實際使用的主檔、因子、ETF、估價／成交價、事件設定；新聞仍中性 |
| `source_snapshot.zip` | 執行前的程式、依賴宣告、主檔；真實資料執行另含行情、歷史基本面、ETF 及除權息參考資料 |
| `source_manifest.json` | 原始檔雜湊與本次程式版本 |
| `corporate_actions_source.json` | CLI 匯入事件檔的原文、來源路徑及雜湊；未匯入時不存在 |
| `integrity.json` | 成功完成輸出的完整檔案清單與雜湊；最後寫入，缺少即非完整封存 |

重播不讀現行股票主檔或行情；驗證程式版本後使用封存的引擎輸入，逐項核對 NAV、持倉、交易、合規、因子輸出及股利權益。數值表使用 `rtol=1e-10, atol=1e-6`；權益帳逐欄相同。這是**決策與結算重播**，不是重新向外網抓取或完整重建原始資料生成流程。

程式版本不同時需先在另一個安全工作目錄還原對應程式，勿覆寫目前專案。ZIP 不包含密鑰、`.env`、正式帳本或環境套件本體。

封存限制：SHA-256 可偵測資料被改但清單未同步修改的情況，不是外部簽章或不可變儲存；若有人同時修改檔案與雜湊清單，需另外使用唯讀備份／外部簽章保障。回測期間若來源檔被修改，拒絕產生成功結果。

## 缺資料與績效修正

- 尚未開始的前置缺檔可列入暖機略過；資料格式錯誤不再被當成暖機。
- 一旦已有回測日，缺檔、日期斷裂或持股估值缺當日收盤價立即停止，不延續舊 NAV。
- 全區間沒有有效日視為失敗，不產出成功報告。
- 年化報酬以初始本金至最終 NAV 計算，使用實際納入的交易日數，含第一天費用與損益。
- 少於 252 日有短樣本警示；年化數字不代表已驗證長期能力。
- 比較基準仍是等權每日再平衡的價格報酬，未含股利，不應將超額報酬解讀為同口徑總報酬 alpha。
