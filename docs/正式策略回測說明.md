# 正式策略回測說明

## 定位

> 2026-10-15 更新：股利權益、缺資料停止、年化報酬與封存保護已擴充；操作及限制以 [回測股利與封存說明](回測股利與封存說明.md) 為準。這不代表違規處置、被動超限寬限、Active Share 連續處置或股票分割已完成。

新版正式回測位於 `src/agent/backtest/`，直接重用 `factor_engine.py`、`strategy.py`、`rules.py` 與 `state.py`；它只重播歷史決策與模擬結算，**不產生 D-Plan、不修改 `data/state/ledger.json`，也不得作為每日正式下單入口**。

執行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m src.agent.backtest.runner --start 2026-10-02 --end 2026-10-13
```

輸出為獨立目錄 `output/backtest/formal_<時間>/`，包含每日 NAV、持倉、交易、合規結果、全候選池因子診斷、設定快照與摘要報告。

輸出目錄必須為 `output/backtest/` 下尚不存在的新子目錄；禁止覆寫。新增股利權益帳、實際每日輸入、程式／資料快照及雜湊清單；`--replay <原始run>` 可驗證並重播。回測開始前缺檔可作暖機略過；開始後缺資料一律停止。年化報酬已改用初始本金及全部有效交易日，包含第一日損益。

股利需另外匯入核實明細，沒有資料不代表沒有股利。現金及配股權益只在明確指定 `--terminal-date` 後計入最終 NAV，不提前增加可交易資產。已知除權息但明細缺漏、分割等未支持事件遇曝險、期末配股缺價均停止，不猜測。

## 舊版基準與新版差異

`data/backtest/` 的 `ic.csv`、`nav_baseline.csv`、`sim_full.csv`、`sim_windows.csv` 是既有研究與參數選擇的基準成果，會完整保留，不被新版覆寫。它們仍可作為歷史比較依據。

新版的新增意義是以現行程式為唯一策略來源，逐日重播：

| 面向 | 舊版成果 | 新版正式回測 |
| --- | --- | --- |
| 策略來源 | 既有研究／組員回測流程 | 直接呼叫目前 `factor_engine.py` 與 `strategy.py` |
| 資料時點 | 依各既有成果定義 | 基本面依 `available_from`，ETF 持股只可用資料日以前快照 |
| 交易 | 彙總結果為主 | 整張、成交均價、手續費、證交稅、現金與持倉逐日結算 |
| 競賽限制 | 部分摘要檢查 | 每日持股數、現金、單檔權重、Active Share 留存 |
| 可稽核性 | 成果檔為主 | 每日因子、持倉、交易、合規、manifest 與程式版本皆封存 |

新版並非宣稱舊版錯誤；它的用途是確認「此刻要提交的正式程式」在同一組歷史資料上是否仍能重現並延伸舊版觀察。新版完成後，應以相同區間比較 NAV、交易、成本、持倉和回撤；差異必須記錄其資料時點或規則原因，再決定是否整併為唯一入口。

## 防止過擬合

1. 固定開發期、驗證期與最後保留期；參數僅能依開發期調整。
2. 驗證期與保留期不得因結果再調參；保留期只作最終定版檢驗。
3. 比較等權候選池、既有舊版基準與 Shadow 研究線，不只看累積報酬。
4. 評估報酬時同時檢查 MDD、換手、成本、集中度與 Active Share；忽略競賽摩擦的結果不可用於定版。
5. 每次回測封存策略 manifest、程式版本、日期範圍與輸入假設；禁止只保留表現較好的實驗。

策略說明文件尚未繳交時，回測可作為正式策略定版依據；繳交後則只能用於監測與下一版研究，不得直接改變本次參賽的選股／配置邏輯。
