# AI CUP 2026 Agent 基金經理人專案設計與執行原則

本文件將競賽辦法轉換為本專案的硬性設計限制。若與一般投資策略、模型偏好或既有實作衝突，**一律以競賽辦法與平台後續公告為準**。本競賽為虛擬模擬投資，不構成投資建議。

## 1. 不可違反的 Agent 原則

1. 投資決策、策略說明、每日決策報告與交易書必須由 AI Agent 產製。人員可維護程式、資料管線與配置，但不得以人工方式直接決定或介入每日交易內容。
2. Agent 必須保存可稽核鏈：輸入資料版本、時間戳、模型／提示詞／設定版本、候選與排除原因、目標權重、訂單、成本、合規結果及最終提交檔雜湊。此紀錄必須能證明報告與交易行為一致。
3. 不可私下共享 Agent 程式、抄襲、攻擊排行榜／系統、干擾他隊或散布不實資訊。
4. 規則引擎採「預先阻擋」原則：若輸入不完整或任何下列硬性規則無法證實通過，Agent 不得產生可提交的正式交易書，狀態應為 `blocked`。

## 2. 固定投資範圍與資料原則

1. 僅可交易主辦方公開的固定150檔：以 **2026年7月底**為基準的上市市值前100大與上櫃市值前50大個股。不得依每日市值替換成分股。
2. `security_master` 必須以主辦方名單為唯一正式來源；沒有正式名單時，不得把測試、範例或自行推估的名單標記為正式候選池。
3. 僅可台股現股、整股交易；禁止融資、融券、借券、放空、當沖及零股。訂單數量須為 1,000 股的整數倍。
4. 收盤價可用於市場資料分析與 NAV 檢核；但**交易成交價**必須使用主辦方採用的當日收盤後成交均價。資料模型必須將分析價格與執行價格分開保存，禁止用收盤價冒充成交均價。
5. 除權息或股票分割由主辦方依市場實況調整持股數／現金並納入 NAV。除息現金不在除息日入帳，而由主辦方累積至初賽結束時納入最終 NAV；本地估值不可將該筆現金提早可用。

## 3. 每日投組與交易合規閘門

交易後投組必須同時滿足下列條件：

|控制項|硬性規則|系統要求|
|---|---|---|
|持股檔數|20–30檔（含）|以交易後、持有股數大於0的代碼計算|
|單檔權重|2330 上限 25%；其餘個股上限 10%|以交易後 NAV 計算；2330 以外一律 10%|
|現金|現金部位 **小於** NAV 的 25%|使用嚴格 `< 0.25`，不可寫成 `<= 0.25`|
|現金餘額|不得為負|成交、費稅後重新計算；所有交易視為全數成交|
|交易成本|手續費 0.1425%、證交稅 0.3%|訂單產生時即納入成本與現金預估；成交方向與平台計算法須可設定、可稽核|
|交易價格|當日成交均價|不可用未來資料於提交時決策；事後以平台規則對帳|
|投資範圍|固定150檔|訂單與交易後部位皆須通過候選池檢查|

價格上漲造成單檔超限時，應標記為「價格波動超限」並在5個交易日內減碼；第6個交易日仍超限會被記警告。若超限原因是加碼交易，當日即為違規。

## 4. Active Share 控制

1. 以投組前10大持股，與主辦方揭露、以 2026-09-11 證交所列表為準的各檔主動型 ETF 前10大持股比較。
2. 計算式：`Active Share = 1/2 × Σ |Wi(投資組合) - Wi(Benchmark)|`。
3. 系統必須保存所用 ETF 成分、日期、來源與每次計算結果。任何參考 ETF 資料缺失時，交易書必須阻擋或提出人工規則確認，不可猜測。
4. 若經主辦方檢視，連續2個交易日低於20%，可能直接取消參賽與晉級資格；內部警戒門檻應設為不低於20%。

## 5. 提交、失效與績效

1. 初賽期間為 2026-10-26 至 2026-11-27。每個台股交易日必須於前一日 19:30 至當日 08:55（以主辦方系統為準）提交當日 Agent 決策報告及交易書；每日每隊最多提交25次。
2. 初賽前五日至首日（2026-10-21 至 10-26）另須繳交由 Agent 產製的 ETF 投資策略說明文件。
3. 24個交易日中至少22日成功提交，才列入初賽報酬率排名。系統需提供提交回條、截止時間、重試次數與當日最終版本紀錄。
4. 未提交、現金負數／現金比例不符、持股數不符、權重超限、持有非150檔、或 Agent 決策與交易行為不一致時：當日交易視為無效，按前一日投組計算 NAV，且當日只記一次警告。累積3次警告即取消資格。
5. NAV 由主辦方於收盤後依「各持股張數 × 1,000 × 當日收盤價 + 現金部位」並扣除手續費及證交稅計算。最終 NAV 為初賽排名依據；同 NAV 時以最大回檔（MDD）較低者勝出。

## 6. 對目前專案的落地要求

- 候選池模組：正式輸出需恰為 TWSE 100 + TPEX 50，且 `max_weight` 必為 2330 的 `0.25`、其餘 `0.10`。
- 市場資料模組：除 OHLCV 外，需保留可對帳的成交均價／執行價欄位與資料截止時間。
- 量價模組：僅對固定150檔排名；可輸出前45檔，不能自行改變候選池。
- Agent／投組模組：交易前後都必須執行本文件第3、4節的規則；任何失敗都不可輸出正式交易書。
- 報告模組：產生內容要能逐筆對應訂單與稽核紀錄，支援主辦方抽檢「決策與交易行為一致」。

## 7. 待以平台公告補齊的實作細節

- 主辦方150檔正式名單與檔案格式。
- 當日成交均價的官方欄位、資料發布時點與四捨五入方式。
- 手續費及證交稅在買／賣方向的精確平台計算、最小費額與進位規則。
- Active Share 的逐檔比較／Benchmark選取細節與官方主動型 ETF 成分檔。
- 每日決策報告、交易書及策略說明文件的官方格式、上傳 API／介面與提交回條格式。

這些未公告項目只能以設定檔標示為待確認，不可由模型或開發者自行臆測。
